A deterministic Python program that writes one funny fortune cookie message for an AI agent — a single line of at most 140 characters — to /output/entry.txt. The fortune warns the agent it will hallucinate a confident answer today: wrong, but beautifully formatted.

## Run it

```sh
python3 main.py
```
